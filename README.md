## Anthonny

**`Desenvolvedor FullStack`**

### Sobre Mim

Me chamo Anthonny Jaaziel Alves Ribeiro de Oliveira, tenho 26 anos, sou de Santo Amaro - BA e desenvolvedor Full Stack em formação. Atuo no desenvolvimento de soluções web ponta a ponta, combinando a construção de interfaces reativas em React.js e JavaScript com a estruturação de backends em Python e Flask. Tenho experiência na implementação da arquitetura MVC, modelagem de dados relacionais e não relacionais utilizando SQLite, MySQL, MongoDB e SQLAlchemy, além do uso de Git e GitHub para controle de versão e pytest para garantia de qualidade e cobertura de testes.
